Customer Churn Prediction Using Machine Learning
Overview

This project focuses on analyzing customer data to predict churn behavior using machine learning techniques. The workflow follows a structured and modular approach to ensure accuracy, scalability, and better insights into customer behavior.

The main steps include:

Data generation and preprocessing
Exploratory Data Analysis (EDA)
Feature encoding and statistical analysis
Visualization of patterns and trends
Model preparation for churn prediction

The goal is to identify customers who are likely to leave a service and help businesses take proactive actions to retain them.

Dataset Source

Synthetic dataset generated programmatically

Features include:

Age
Gender
Tenure
Balance
Credit Score
Estimated Salary
Number of Products
Active Membership Status

Target Variable:

Customer Churn (0 = Not Churned, 1 = Churned)
Objectives
Analyze customer behavior and financial patterns
Identify key factors influencing churn
Understand relationships between features and churn
Build insights that help reduce customer attrition
Support business decisions with data-driven analysis
Project Highlights
Data Preprocessing
Generated a large synthetic dataset
Encoded categorical variables (Gender, Active Member) into numerical format
Structured and cleaned the dataset for analysis
Exploratory Data Analysis (EDA)
Analyzed churn distribution across customers
Studied relationships between features such as:
Age vs Churn
Balance vs Churn
Credit Score vs Churn
Tenure vs Churn
Identified patterns influencing churn behavior
Statistical Analysis
Calculated mean, median, mode, and standard deviation
Examined summary statistics to understand data distribution
Measured churn rate and customer segments
Data Visualization
Count plots for churn distribution
Bar plots for categorical relationships
Box plots for numerical feature comparison
Correlation heatmap to identify feature dependencies
Histograms to understand feature distributions
Insights Extraction
Customers with low balance tend to churn more
Lower credit scores are associated with higher churn
Inactive members show higher churn probability
Short tenure customers are more likely to leave
Number of products impacts customer retention
Model Readiness (Future Scope)
The dataset is prepared for machine learning model training
Classification algorithms such as Logistic Regression, Random Forest, or Decision Trees can be applied
Model evaluation can include:
Accuracy
Precision
Recall
Confusion Matrix
